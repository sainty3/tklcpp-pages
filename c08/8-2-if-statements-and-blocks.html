隐式语句块#

如果程序员没有在 if 语句或else语句的部分声明一个语句块，则编译器将隐式声明一个。因此：

代码
if (condition)
    true_statement;
else
    false_statement;

等价于：

代码
if (condition)
{
    true_statement;
}
else
{
    false_statement;
}
